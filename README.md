# AluraStore
Desafio é iniciar o desenvolvimento das suas habilidades em análise de dados com Python.


**Desafio de Análise de Dados com Python**
📊 Objetivo
Este desafio tem como principal objetivo iniciar o desenvolvimento das suas habilidades em análise de dados com Python. A proposta é que você pratique a manipulação, visualização e interpretação de dados para extrair insights relevantes.

📁 Estrutura do Projeto
Para que você possa se concentrar na lógica da análise, disponibilizamos um caderno Jupyter base neste repositório, com quatro bases de dados já preparadas. Assim, você não precisa se preocupar com a extração dos arquivos CSV e pode ir direto ao ponto: analisar os dados.

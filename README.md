**Desafio de Análise de Dados com Python**

📊 Objetivo


Este desafio tem como principal objetivo iniciar o desenvolvimento das suas habilidades em análise de dados com Python. A proposta é que você pratique a manipulação, visualização e interpretação de dados para extrair insights relevantes.

📊 Bases de Dados


O projeto utiliza quatro conjuntos de dados principais, que foram fornecidos no desafio:
clientes.csv: informações demográficas dos clientes
produtos.csv: detalhes dos produtos disponíveis
vendas.csv: histórico de transações
pagamentos.csv: formas de pagamento utilizadas nas compras

🧪 Etapas da Análise


Carregamento e inspeção inicial dos dados
Limpeza e preparação das bases
Análise exploratória com visualizações
Geração de insights sobre o comportamento dos clientes e desempenho das vendas
Conclusões baseadas nas evidências encontradas

📌 Principais Insights


Identificação dos produtos mais vendidos e com maior faturamento
Comportamento dos clientes por região
Análise de formas de pagamento mais utilizadas
Tendências de vendas ao longo do tempo

💡 Conclusão


Esse projeto foi uma excelente oportunidade para praticar a análise de dados com Python, aprimorar o uso de bibliotecas de visualização e desenvolver insights práticos a partir de dados reais de negócios.
